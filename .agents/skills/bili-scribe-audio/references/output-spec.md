# 输出规则

必需：course_manifest.json、understanding_manifest.json、大纲.md、讲义/、术语表.md、习题讲解.md、交付报告.md。有课本才加 textbook_manifest.json 和互补大纲.md。

每讲首行包含 lesson_id，例如 # L001 · 条件概率。概念、公式条件、实际推导、例题、重点与易错点都据转录。课堂引用包含讲次、时间与理解条目 ID；粗略时间明确标注。课件内容引用文件、页/幻灯片/段落；课本补充引用选中章节 ID、印刷页与 PDF 物理页的已确认映射。

重点保留支持原话与五类准确标签；略过事件仅记明确口述，DEFERRED 在后续核对后标 RESOLVED/UNRESOLVED。习题独立成册，课程完整解/课程部分解/课程仅答案分开，AI 补解另列。

没有画面证据，不输出 [视频画面]；画面独有的参数、步骤和图形关系列缺失。讲义与 AI 说明不可伪装成课堂内容。交付报告说明 transcript-only、未直接听取原始音频、覆盖、缺失、粗略时间、语义抽查与尚未核对的内容。结构校验不能证明语义正确或操作可复现。
