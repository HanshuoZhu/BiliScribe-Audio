# 常见问题

| 现象 | 检查与处理 |
|---|---|
| 找不到 Skill | 新开 Codex 对话；安装器输出目录下应有 SKILL.md；确认安装到实际用户的 CODEX_HOME/skills，避免多个副本 |
| 移动仓库后出错 | 新安装器是完整复制；旧版本若使用路径入口，重新安装独立 Skill；已建虚拟环境移动后也可能需要重建 |
| 缺 requests/pypdf | 运行实际使用位置的 scripts/setup.py；不要混用系统 Python 和 Skill .venv |
| 缺 faster_whisper | 仅需要本地 ASR 时 setup.py --with-asr；已有转录不需要 |
| FFmpeg 缺失或媒体解码失败 | doctor.py 检查；imageio-ffmpeg 自带可执行文件，或设置 FFMPEG 为自己的路径；损坏媒体重新获取；弱校验只在明确选择时用 |
| B 站限制、403、没有字幕 | 降低频率，确认你有访问权；改用授权本地媒体/转录；不绕平台访问控制；UP 搜索接口可能需要平台签名，显式 BV 最可靠 |
| 云 ASR 不兼容或超时 | 核对所选服务的兼容接口与限制；不要上传密钥到 issue；选择 local 或提供已有转录 |
| 本地模型下载失败 | 检查网络和自己的模型缓存；可自行设置可信 HF_ENDPOINT；医生检查不下载模型、不证明转写质量 |
| PDF 全是空文字 | 通常是扫描件；使用已授权 OCR 或 Vision；不能把空内容当完成 |
| PPT 只有图或布局乱 | Audio 仅做文字提取，请用 Vision 看图或提供文字版 |
| 输入更新后理解失效 | 输入指纹校验是预期行为；重新准备材料，并重新理解受影响包 |
| validate_course 通过但讲义不准确 | 自动检查没有语义理解能力；对照原证据修正原意、公式、条件 |
| 无时间 TXT 被拒绝 | 为对应讲次提供真实时长；仅生成 coarse 全讲文字，不允许假时间 |

Audio 不识别视频图像。画面里才有的公式、数值或菜单路径列为未验证，不用 AI 推断冒充课程证据。

排查先提供版本、Python/系统、执行命令和脱敏错误。先本地复现，不上传私人课程、转录、教材、账号 Cookie 或真实 .env。完整边界见 [路线图](roadmap.md)。
