# 能力边界与路线图

## 1.0.0 已实现

- 稳定 BV/CID/讲次身份，候选确认、分 P 顺序与合集分页。
- 字幕优先、云或本地 ASR、带时间 JSON，支持已有 SRT/MD/TXT。
- 当前 Codex 理解记录、原话引用、覆盖与输入变化检查。
- PPTX/PDF/DOCX 文字、课本选章与印刷/PDF 页码映射。
- 强制 transcript-only，拒绝画面理解模式，避免未观察的画面声明。
- Windows/macOS/Linux 依赖入口，独立 Skill 安装与离线回归。

## 当前限制

- B 站网络、登录与风控会变化；不能保证所有公开课程能自动获取。授权本地材料是可用替代。
- 云服务的“兼容”实现不完全一致；未在所有服务上实测。长课程的真实 ASR 质量需独立验证。
- 转录识别错误会影响理解。粗略时间不等于精确句级定位。
- 不处理视频画面和图片式材料的视觉语义；也不保证操作类视频能仅凭口述复现。
- 自动校验只证明结构与证据关系，不是语义评价器。首次公开发布前的离线测试不等于真实课程基准。

## 下一步（待真实反馈验证优先级，不承诺日期）

1. 收集三类明确授权的完整课程案例：理论讲解、公式推导、PPT 文字讲解；公开输入范围、未完成项与审查记录。
2. 按错误类别记录重点判断保真、章节映射、转录术语纠错，建立可重复的人工验收数据。
3. 增强断点继续和长课程分批体验，保证输入更新后只重做受影响部分。
4. 根据贡献者实际需要改善文档与跨平台安装，不增加未经验证的界面或模型服务。

功能请求请说明当前材料、期待结果与可公开复现的示例。没有证据支持的功能不写进“已完成”。
